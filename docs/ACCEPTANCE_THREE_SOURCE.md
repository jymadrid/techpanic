# 指数三源验收

## 规则

在线运行逐一查询东方财富、腾讯、新浪全部三个源。有效日线的截止日越新越优先；同日优先级 em > tx > sina。所有源不可用才使用通过完整性检查的缓存。离线模式不联网。

腾讯历史分年度请求未复权 day 数据，过滤前置滚动窗口，拒绝错误标的、失败分段或历史空段，不将 qfqday/hfqday 混入，也不拼接其他源。HTTP 超时/重试/总预算受控。内置标的查询从科创50 2020、创业板指 2010、上证50 2004 开始；非内置标的从 1990 开始，若存在无效历史段需新增明确适配，不能保证任意标的可用。

## 测试

- Windows 全套 159 passed。ruff 检查 src/tests/scripts 通过。
- 覆盖三源全调用、最新日期选择、同日三级排序、单源/全部失败、无效值、历史年度分段、前置滚动窗口过滤、总预算、覆盖差异警告、JSON 来源和离线零请求。
- 不改 PI 权重和算法。替换整段行情源的精度、覆盖差异可能影响历史分位。
