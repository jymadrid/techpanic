# 方法学 v2：定义冻结，解释收敛

项目沿用 PI 名称，输出是约定权重的相对市场压力，不是心理恐慌或未来下跌概率。金融有效性未验证；工程复算与经济构念验证分开。

## 冻结公式

收益 r=close/previous_close−1。RV20/RV5 为20/5观测会话的样本标准差（ddof=1）×√252×100。

```text
dRV = RV20_t - RV20_{t-1}
RV52 = RV5/RV20 - 1
semi = Var(min(r,0))/Var(r)
doup = Std(min(r,0))/Std(max(r,0))
S = .5 P(dRV) + .5 P(RV52)
A = .5 P(semi) + .5 P(doup)
F = P(QVIX)
PI_full_raw = .40 S + .35 A + .25 F
PI_price_raw = (.40 S + .35 A)/.75
EMA span=3, adjust=False
```

P 为包括当日、average ties 的扩展分位，输出0—100，不是经典z分数。semi 是截断负收益的中心化方差比，不是传统 E[min(r,0)^2] 下行半方差；保持原公式但不混淆命名。S反映波动加速，旧极端收益离开窗口也会改变它，不保证持续压力时高分。F是第三方隐含波动代理，可能含风险溢价和流动性，不唯一识别恐惧。

## 缺失与时间

无效/非正/无穷价格不参与，pct_change不自动填充。零上涨离散度导致doup无定义时不报无穷分位；因子不足输出无当前值。QVIX缺失的完整口径不能forward-fill为当日。EMA恢复时的状态按pandas当前adjust=False/ignore_na=False规则冻结。原始价格上计算n行收益后对齐过滤的因子表，不在dropna后的表重新跨行。日历完整覆盖时缺会话以NaN重索引；没有日历时仅称观测行，不声称精确5交易日。

## 分级与可比性

按各口径历史25/50/75/90分位分为低位、中低位、中高位、高位、极高位；这是相对罕见程度，非情绪认证或概率。A/B虽都0—100仍非共同量尺，不相减。不同历史起点和可得F改变校准支持。fixed阈值本身不能保证来源/历史跨版本可比。

默认expanding日期前缀因果：固定过去输入追加未来行，历史不变；来源修订、补历史、变参数才可能重写过去。full_sample有未来样本，仅研究重算，不称实时无前视。按日期裁当前下载历史不是当时已知重放，只有有接收时间的证据版本可用于knowledge-as-of。

## 验证

独立算术oracle、前缀不变和故障注入验证工程；官方独立参考验证样本数值；独立同期卖压/流动性目标加预注册连续留出和时间块置信区间验证有限经济主张。未取得外部材料则结果证据不足。详见 [审计协议](AUDIT_PROTOCOL.md)。权重不调优、无交易盈利验收，来源影响单独报告。
