# 方法学

本文档说明 PI 是怎么算出来的、每个设计选择为什么这样定、以及它的局限。

> **重要概念澄清**：本项目代码中出现的 "`z()`" 指的是
> **扩展窗口分位标准化**（expanding-window percentile rank，输出 0–100），
> **不是** `(x - 均值) / 标准差` 的经典 z 分数。
> 两者都实现「跟历史比有多极端」的目的，但分位版本对厚尾和异常值更稳健，
> 而且天然落在 0–100 的有限区间内。下文一律称「分位标准化」。

---

## 1. 为什么要三个因子

单看波动率不足以刻画「恐慌」。恐慌在金融学里至少包含三个可分离的现象：

| 现象 | 问题 | 对应因子 |
|---|---|---|
| 波动本身变大了 | 市场不安分 | 突发性 S |
| 下跌时的波动远大于上涨时 | 市场对坏消息更敏感 | 不对称性 A |
| 市场**预期**未来会更糟 | 前瞻性恐惧 | 前瞻恐惧 F |

三者经济含义不同，相关性不完美，所以合成比任何单一指标都更有区分度。

关键区分：**恐慌 vs 狂热**。两者的波动都大（S 都高），区别在 A——
恐慌时下跌波动放大（A 高），狂热时上涨波动同样大（A 不高）。
这就是为什么 A 是权重第二高的因子，也是为什么必须同时给出「方向」。

## 2. 公式

设 `r_t` 为日简单收益率，即 `close.pct_change()`。

### 2.1 基础量

```
rv20_t = std(r_{t-19..t}) × √252 × 100        # 20 日已实现波动率（年化，%）
rv5_t  = std(r_{t-4..t})  × √252 × 100        # 5 日已实现波动率

dRV_t  = rv20_t − rv20_{t-1}                  # 长期波动的日度变化
RV52_t = rv5_t / rv20_t − 1                   # 短期相对长期的抬升

neg_t  = min(r_t, 0)                          # 只留下跌
pos_t  = max(r_t, 0)                          # 只留上涨

semi_t = var(neg, 20) / var(r, 20)            # 下行半方差占比
doup_t = std(neg, 20) / std(pos, 20)          # 下跌波动 / 上涨波动
```

### 2.2 合成

```
S = ½ · P(dRV)   + ½ · P(RV52)
A = ½ · P(semi)  + ½ · P(doup)
F = P(qvix)

PI = 0.40·S + 0.35·A + 0.25·F
PI_smooth = EMA(PI, span=3)
```

其中 `P(·)` 是扩展窗口分位标准化，输出 0–100。

### 2.3 两个口径

**A 完整口径**：上式原样。依赖 QVIX，而 QVIX 盘后发布，可能滞后 1 个交易日。

**B 即时口径**：去掉 F，把剩余权重归一化到 1：

```
PI_price = (0.40·S + 0.35·A) / (0.40 + 0.35) = (0.40·S + 0.35·A) / 0.75
```

除以 0.75 是为了让两个口径**量纲一致**（都落在 0–100 的同一尺度上），
这样它们可以各自与自己的历史比较。

> ⚠️ **但量纲一致不等于可以相减。**
> `A − B` 的差值同时包含「缺少 F 因子」和「数据日不同」两个原因，
> 无法拆分。想看今天的新增冲击，请比较**同一口径**的今日与昨日。

### 2.4 分级

用历史分位在 `[0.25, 0.50, 0.75, 0.90]` 处的值作为四道分界线，划出五档：

| 分级 | 条件 |
|---|---|
| 平静 | `PI < p25` |
| 常态 | `p25 ≤ PI < p50` |
| 警戒 | `p50 ≤ PI < p75` |
| 恐慌 | `p75 ≤ PI < p90` |
| 极度恐慌 | `PI ≥ p90` |

锚点的三种算法：

| 算法 | 定义 | 前视偏差 | 用途 |
|---|---|---|---|
| `expanding`（默认） | 第 t 天只用 t 及之前的样本 | **无** | 实时使用 |
| `full_sample` | 用全部样本 | **有** | 复现历史报告 |
| `frozen` | 配置写死的阈值 | 无 | 对外引用、跨版本比较 |

## 3. 五个关键设计选择

### 3.1 用扩展窗口分位，而不是滚动 z 分数

- **分位**天然落在 0–100，不会因为一次极端行情把后续几天的值全部压平。
- **扩展窗口**（而非滚动窗口）意味着「历史」随时间累积：早期读数基于较少样本，后期基于更多样本。
- 代价：新数据到来会让历史分位发生极微小变化。这是消除前视偏差的必然成本。

最小样本数 `min_periods = 60`：样本少于 60 个交易日不给值，避免早期读数不可靠。

### 3.2 EMA 缺值日必须显式置为 NaN

计算 `PI_full` 的平滑值用 `ewm(span=3, adjust=False)`。
问题在于：**pandas 的 ewm 会跳过 NaN，并继续沿用上一日的内部状态**。

结果就是：QVIX 缺失的那一天，平滑值仍然是一个数——来自上一次有 QVIX 时的值。
如果直接输出，用户看到的「完整口径数据日」就是错的。

本项目的处理：

```python
d["PI_full"] = d["PI_full_raw"].ewm(span=cfg.ema_span, adjust=False).mean()
d.loc[d["F"].isna(), "PI_full"] = np.nan     # 缺值日置回 NaN
```

**这是本项目相对参考实现的一处有意修正**，详见 [VALIDATION.md](VALIDATION.md)。

### 3.3 零值视为缺失

QVIX 上游用 `0` 表示缺失。波动率不可能为 0，
所以读到 0 一律当缺失剔除，**绝不能**把 0 算进指标——那会系统性压低 PI。

同理，负值直接判为数据错误并拒绝整段数据。

### 3.4 权重是约定，不是真理

`0.40 / 0.35 / 0.25` 是研究文档给出的约定值。
本项目**不声称**这是唯一正确的权重。修改权重会改变读数定义，因此：

- 配置里可以改，但改了之后读数**不再与历史可比**；
- 所有回归测试会随之失效（这是有意的保护机制）。

### 3.5 方向必须与水平一起看

方向由 5 日收益率（ret5）判定：为负则「向下」，为正则「向上」，缺失为「未知」。

这不是装饰。同一个 PI 高分：

- 方向向下 → **恐慌**（在跌 + 波动放大 + 下跌不对称）
- 方向向上 → **狂热**（在涨 + 波动放大）

把两者混为一谈是使用本指标最常见的错误。

## 4. 局限与已知偏差

### 4.1 样本起点不一致

指数的历史比 QVIX 长（科创50 指数自 2020 年，其 QVIX 自 2023 年 6 月）。
早期只有 `PI_price` 可用，因此：

- `PI_price` 的分位锚点覆盖的样本区间比 `PI_full` 长；
- 两者的「历史分位」不可直接互换理解。

### 4.2 扩展窗口的早期不稳定性

前 60 个交易日不给值；第 60–200 个交易日之间的分位估计方差较大。

### 4.3 QVIX 列号是硬编码的

列号是硬编码切片（见 [DATA_SOURCES.md](DATA_SOURCES.md)）。
上游改版会导致取错列，本项目用三道防线拦截，但无法 100% 消除。

### 4.4 上游重算会让读数有微小漂移

QVIX 上游**每次请求都会重算历史值**（实测两次抓取的重叠日中位偏差 1%~2%）。
经过分位标准化后，这会让 F 因子变化零点几个点，PI 随之变化约 0.1~0.5。

结论：**「同一份输入」在跨次运行间并非逐位相同**，因为输入本身在变。
需要严格可复现的引用，请把当时的 `data/cache/qvix/*.csv` 一并留档。
（算法本身是确定性的：给定同一份输入，输出逐字节相同，由测试锁定。）

### 4.5 PI 是状态量，不是预测量

PI 没有、也不应被解释为对未来的预测。
把它当交易信号使用超出了本项目的设计意图，后果自负。

### 4.6 波动率年化用 252

中国市场每年交易日数在 242–244 之间浮动。
用 252 会让年化波动率略高于用 244 的结果（约 +1.6%）。
因为最终经过分位标准化，这个常数对 PI 的影响可忽略；
但如果你要引用 `rv20` 的绝对数值，请注意这一点。
