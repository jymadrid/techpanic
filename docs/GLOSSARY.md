# 术语：相对压力，不是心理认证

- S：波动变化与短/长波动比的扩展分位，偏加速度，不保证持续高压力时高分。
- A：截断负收益中心化方差比与负/正离散度比。不是传统下行半方差定义，也不证明心理敏感性。
- F：第三方QVIX隐含波动代理，可能含风险溢价与流动性。期权真实标的身份未验证。
- A完整/B价格：因子与日期不同；0—100范围相同不构成共同量尺，不可相减。
- 分级：低位、中低位、中高位、高位、极高位，只指各自历史位置。
- 方向：n观测行收益符号，完整提供日历时按会话；不是恐慌/狂热认证。
- 前缀因果：固定过去输入追加未来不改过去；不同于数据在当时可得。
- 当时已知重放：按首次观察和证据选版本，采集前未知不能伪造。
- 官方参考：同对象、同日、同单位独立材料，供应商多数相同不是真值。
- 哈希：本地留存完整性，不是上游签名、许可或真实性。
