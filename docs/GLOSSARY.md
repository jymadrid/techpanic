# 术语表

## 指标相关

**PI（Panic Index，恐慌指数）**
本项目计算的核心指标，取值 0–100。由三个因子加权合成，衡量 A 股科技板块的恐慌程度。
**不是**官方波动率指数。

**S（突发性）**
短期已实现波动率相对长期已实现波动率的抬升幅度，标准化到 0–100。
直觉：市场「突然不安分」的程度。

**A（不对称性）**
下跌时的波动相对上涨时波动的放大程度，标准化到 0–100。
直觉：市场对坏消息比对好消息更敏感的程度。这是「恐慌」区别于「狂热」的关键因子。

**F（前瞻恐惧）**
期权隐含波动率（QVIX）相对其历史水平的 z 分数，标准化到 0–100。
直觉：期权市场对未来波动的前瞻定价。**唯一前瞻性因子**，也是唯一有发布延迟的因子。

**完整口径（A 口径）**
包含全部三个因子 S/A/F 的 PI。因依赖 QVIX，数据日通常滞后 1 个交易日。

**即时口径（B 口径）**
只用价格信息的 PI：对 S 和 A 按剩余权重归一化，即 `PI_price = (0.40S + 0.35A) / 0.75`。
当日收盘即可计算。

**方向**
由 20 日动量判定的趋势方向（向上 / 向下）。**必须与 PI 水平结合判读**：
PI 高 + 向下 = 恐慌；PI 高 + 向上 = 狂热。

**历史分位**
当前读数在过去所有可用读数中的百分位排名。

## 分级

**平静 / 常态 / 警戒 / 恐慌 / 极度恐慌**
五档分级，由历史分位在 `[0.25, 0.5, 0.75, 0.9]` 处的分界决定。

**锚点（anchors）**
用来划分五档的分位阈值本身。

**扩展窗口锚点（expanding anchors）**
默认方案：第 t 天的锚点只用第 t 天及之前的样本计算。
**严格无前视偏差**，因此历史分级在实时场景下是可复现的。

**全样本锚点（full sample anchors）**
用全部样本（含未来数据）计算锚点。会产生前视偏差，
仅用于复现历史报告或离线研究。

**固定锚点（frozen anchors）**
在配置里写死的阈值。可复现、可对外引用，不随数据更新而漂移。

**前视偏差（look-ahead bias）**
在计算第 t 天的指标时用到了 t 天之后的信息。
它会让回测结果虚假地变好，是量化研究中最常见、最致命的错误之一。

## 波动率

**RV（Realized Volatility，已实现波动率）**
由历史收益率计算的实际波动率，本项目用 20 日（长期）与 5 日（短期）两个窗口。

**QVIX**
中国市场的期权隐含波动率指数，类似美股的 VIX。
本项目使用上交所/深交所相关期权品种的 QVIX 序列，来自 `1.optbbs.com`。

**隐含波动率（Implied Volatility）**
从期权市场价格反推出来的、市场对未来波动的预期。
与已实现波动率的关键区别：它是**前瞻性**的。

**半方差（semi-variance）**
只对下跌方向（或上涨方向）的收益率计算方差，用来度量波动的不对称性。

**年化**
把日频波动率换算到年频，本项目用 252 个交易日。

**z 分数（z-score）**
`(x - 均值) / 标准差`，衡量一个观测值偏离历史中枢多少个标准差。

**百分位排名（percentile rank）**
一个值在历史样本中低于它的比例，取值 0–100。

## 工程相关

**缓存（cache）**
上次成功抓取的数据，存放在 `data/cache/`。
重新计算时优先使用，避免重复请求。

**降级（degradation）**
主路径失败时的可解释回退，例如抓取失败时使用缓存。
**所有降级都会显式标注**，绝不静默发生。

**退出码（exit code）**
程序结束时返回给系统的数字，表示运行状态。
本项目约定：0 成功 / 2 部分降级 / 3 无数据 / 4 环境问题 / 5 参数错误 / 130 中断。

**原子写（atomic write）**
先写临时文件、再原子替换目标文件。
保证任何时刻中断都不会留下半截损坏的文件。

**清单（manifest）**
`data/cache/_manifest.json`，记录每份缓存的来源、行数、
最后日期、抓取时间与文件哈希，用于溯源与排障。

**交叉校验（cross check）**
把新抓取的数据与本地已有缓存在重叠日期上对比。
这是发现「上游悄悄改列导致取错数据」最有效的一道防线。
